# 📰 TechNews

## About the Project

TechNews is a static technology news portal. The page organizes headlines and short articles about robotics, artificial intelligence, the internet, virtual reality, wearable devices, and other topics.

Content is grouped into featured stories, weekly highlights, artificial intelligence articles, and recommendations. The layout adapts to different screen widths and includes a horizontally scrollable category navigation bar.

## 🎯 Features

* **Editorial highlights:** displays featured headlines with images and category labels.
* **News sections:** groups content into weekly highlights, artificial intelligence stories, and recommendations.
* **Category navigation:** uses internal links to navigate to some page sections.
* **Drag-to-scroll navigation:** lets users drag the category bar with a mouse. On touch screens, it uses the browser's native scrolling.
* **Responsive layout:** rearranges content to fit different screen widths.

## 🛠️ Technologies Used

* **HTML5:** structures the page content and sections.
* **CSS3:** defines the visual design, grid layout, and responsive rules.
* **JavaScript:** adds drag-to-scroll behavior to the horizontal navigation.
* **Google Fonts:** loads the Archivo and Archivo Black typefaces.
* **SVG and PNG:** used for icons, the logo, news images, and the advertisement area.

## 📝 How to Use

1. Download or clone the repository.
2. Open the `portal-de-noticias` folder.
3. Open `index.html` in a browser.
4. Keep an internet connection available to load Google Fonts.
