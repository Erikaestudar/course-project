# 💻 Portfolio Dev

## 📌 About the Project

Portfolio Dev is a static page presenting the profile of a fictional full-stack developer, selected projects, services, and a contact area. It is intended for people interested in the developer's work, such as potential clients and recruiters.

The page was created by Erika Sugawara as part of a Rocketseat course. Martina Santos and the profile details shown on the page are fictional. The site uses HTML and CSS, with no JavaScript or build tools.

## 🎯 Features

- **Profile introduction:** shows the name, role, description, and technologies associated with the fictional profile.
- **Project grid:** displays six projects with thumbnails, descriptions, and links to their pages.
- **Services section:** lists services related to websites and apps, APIs and databases, and DevOps.
- **Responsive layout:** adjusts the project and technology layouts to different screen widths.
- **Contact area:** displays visual links for LinkedIn, Instagram, GitHub, and email. These links currently use `#` as their destination.

## 🛠️ Technologies

- **HTML5:** page structure and content.
- **CSS3:** styling, Grid and Flexbox layouts, colors, typography, and responsive adjustments.
- **Google Fonts:** loads the Asap, Inconsolata, and Maven Pro typefaces.

## 📝 How to Use

1. Open the published page using the link above.
2. To view the files locally, download or clone the repository that contains the `portfolio-dev` folder.
3. Open `portfolio-dev/index.html` in a browser. To edit the files, open the folder in your code editor.
4. To change the styles, edit the relevant files in `styles/`.

## 💡 What You Can Learn

The project demonstrates how to structure a page with semantic HTML, organize styles across separate CSS files, and use Flexbox, Grid, and media queries. It also shows how to present projects in cards with images and links.
