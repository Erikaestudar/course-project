# 💻 Portfólio Dev

## 📌 Sobre o Projeto

Portfólio Dev é uma página estática que apresenta o perfil de uma desenvolvedora full-stack fictícia, seus projetos em destaque, os serviços que oferece e uma área de contato. O conteúdo é voltado a pessoas interessadas em conhecer o trabalho da profissional, como potenciais clientes e recrutadores.

A página foi criada por Erika Sugawara como projeto de curso da Rocketseat. O nome Martina Santos e os dados de perfil exibidos são fictícios. O site usa HTML e CSS, sem JavaScript ou ferramentas de build.

## 🎯 Funcionalidades

- **Apresentação de perfil:** exibe nome, cargo, descrição e tecnologias associadas ao perfil fictício.
- **Grade de projetos:** mostra seis projetos com miniaturas, descrições e links para suas páginas.
- **Seção de serviços:** apresenta serviços relacionados a sites e aplicativos, APIs e bancos de dados, e DevOps.
- **Layout responsivo:** ajusta a apresentação dos projetos e das tecnologias conforme a largura da tela.
- **Área de contato:** exibe opções visuais para LinkedIn, Instagram, GitHub e e-mail. Os links dessa área ainda usam `#` como destino.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estrutura e conteúdo da página.
- **CSS3:** estilos, layout em grid e flexbox, cores, tipografia e ajustes responsivos.
- **Google Fonts:** fornece as fontes Asap, Inconsolata e Maven Pro.

## 📝 Como Usar

1. Acesse a página publicada pelo link acima.
2. Para visualizar os arquivos localmente, baixe ou clone o repositório que contém a pasta `portfolio-dev`.
3. Abra `portfolio-dev/index.html` em um navegador. Para editar, abra a pasta no seu editor de código.
4. Se alterar os estilos, use os arquivos correspondentes dentro de `styles/`.

## 💡 Recursos de Aprendizado

O projeto demonstra a estruturação de uma página com HTML semântico, a organização de estilos em arquivos CSS separados e o uso de Flexbox, Grid e media queries. Também mostra como apresentar projetos em cartões com imagens e links.

## 🚀 Sugestões de Melhorias

- Substituir os destinos `#` da área de contato pelos perfis e endereço de e-mail corretos.
- Atualizar os dados fictícios do perfil quando houver informações profissionais definitivas.
- Incluir estados de foco visíveis para facilitar a navegação por teclado.
- Conferir os textos alternativos das imagens para que descrevam melhor seu conteúdo.
