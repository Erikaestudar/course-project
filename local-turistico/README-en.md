# Tourist Spot - Discover Busan

## 📍 About the Project

An informative and interactive website that showcases the main tourist attractions of Busan, South Korea's second-largest city. The project highlights three must-see destinations for history enthusiasts, focusing on century-old Buddhist temples and historic parks.

The website is responsive and offers an intuitive user experience, allowing visitors to explore detailed information about each attraction in an interactive way.

## 🎯 Features

- **Visual Presentation**: Hero section with featured image and general description of Busan
- **Interactive Cards**: Accordion system with three main tourist destinations
- **Responsive Design**: Adapted for different screen sizes
- **Dynamic Dropdown**: Click on cards to expand and view detailed information
- **Intuitive Navigation**: Clean and user-friendly interface

## 🛠️ Technologies Used

- **HTML5**: Semantic page structure
- **CSS3**: Modularized and responsive styling
  - Global: General styles and variables
  - Layout: Project structure and grid
  - Article: Specific styles for articles and cards
- **JavaScript (Vanilla)**: Dropdown interactivity
- **Google Fonts**: Typography (Open Sans)

1. Open the `index.html` file in a web browser
2. Explore the main page with information about Busan
3. Click on card titles to expand and see details of each attraction
4. Click again to collapse the information

## 🎨 Featured Destinations

### 1. Haedong Yonggungsa Temple

One of the few Korean temples built by the seaside, offering views of the East Sea and surrounding mountains.

### 2. Beomeo-sa Temple

One of the largest temples in South Korea, located at the top of Geumjeongsa mountain, preserving Joseon Dynasty architecture.

### 3. Yongdusan Park

Centrally located, housing the 120-meter Busan Tower, museums and cultural exhibitions.
